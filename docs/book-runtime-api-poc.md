# BookRuntime API — первый POC

## Контракт

`BookRuntime` создаётся из настоящих `P`, `H1`, `H2` ядра и режима исполнения
(`editor` или `reader`). В редакторе объект передаётся в кастом через
`CoreComponentNode`, а в читателе — через `renderNode`.

JSON книги не меняется: он хранит только `package` и `name` компонента.
Реальные функции и компоненты передаются через React props при рендеринге.

## Типы

Пока публичный контракт описан в
`packages/book-builder/src/customComponents/runtime.ts`. Тот же контракт
подготовлен в отдельном пакете `@active-book/types` для будущей публикации.
Внешняя библиотека может временно использовать локальную копию деклараций
и заменить её на `import type { BookComponentProps } from '@active-book/types'`,
когда пакет станет доступен.

Это POC: намеренно предоставлены только `P`, `H1`, `H2` и `mode`.
Весь остальной API ядра будем добавлять после проверки способа передачи.
Существующий `sharedReactPlugin` по-прежнему нужен для общего React.

## Проверка

1. Собрать `activeBook-custom-test` из ветки `feature/book-runtime-consumer` (`npm run make`).
2. Запустить редактор из ветки `feature/book-runtime-api`.
3. Импортировать `.tgz` и вставить `RuntimeExample`.
4. Убедиться, что заголовок и параграф используют настоящие стили ядра,
   счётчик нажатий работает и выводится режим `editor`.
5. Собрать книгу и проверить тот же компонент с режимом `reader`.

Сборка и браузерные тесты должны быть выполнены перед слиянием.
